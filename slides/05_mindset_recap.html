Mindset Recap

🎯 把每一件事都當作練習
🧘 覺察 / 正念 / 止於情緒 / 核對：情緒是真的，但它可能帶來假的想像
🔍 復盤循環：覺察 → 回顧 → 微調 → 積累
🌱 人生是用來優化的，不是拿來計畫的
在這個單元，我們回顧了幾個重要的心態觀念：

1. 把每一件事都當作練習：無論是工作、生活還是人際關係，每一次的經歷都是一個練習的機會。
2. 覺察 / 正念 / 止於情緒 / 核對：學會覺察自己的情緒，並理解情緒背後的想法和感受。但，也請提醒自己，情緒有可能帶來假的想像，在進入小劇場前，務必先核對。
3. 復盤循環：透過覺察、回顧、微調和積累，讓自己不斷進步。
4. 人生是用來優化的，不是拿來計畫的：我們不需要完美的計畫，而是要在實踐中不斷調整和優化。
